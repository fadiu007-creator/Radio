# Music folder

Put your MP3 files in this folder, then list each file name in `playlist.json` in the repo root.

Name files like `Artist - Title.mp3` so the player can show the artist and title.

Example `playlist.json`:

```json
{
  "tracks": [
    "Artist One - First Song.mp3",
    "Artist Two - Second Song.mp3"
  ]
}
```

Tips:
- Only upload music you own or are licensed to play publicly.
- Keep each file under 100 MB and the whole repo under about 1 GB.
- Use normal constant-bitrate MP3s (128-192 kbps) so the length is read correctly.
